WildBits K2 / Jr2 — Absolute address map (A[23:0])

The address every master speaks: the CPU through its LUT entry (entry × $2000 + offset, for every entry), VICKY’s bitmap / tile / sprite address registers, the DMA registers and the debug port. FNX6809 Core2X rc15 cores (K2 and Jr2, deployed 2026-09-13); Foenix F256 memory map Revision E (2026-03-13) with its $D0–$EF row corrected to the identity address. “Physical home” is where the bytes actually live; for RAM it is the same number as the absolute address.

1 MB of the 2 MB part is in use (512 + 256 + 256 KB), 1 MB is not reachable by any address (768 + 128 + 128 KB). Since rc15 there is no address translation anywhere: the MMU emits block × $2000 for every RAM entry and the SRAM pins carry that number / 2.
